## 💡 Sobre o Projeto

O **JOVI FlowCam** é um projeto web desenvolvido para resolver as principais dores de usuários comuns na hora de tirar fotos, gravar vídeos ou digitalizar documentos pelo celular. 

Em vez de exigir softwares de edição pesados pós-captura, a aplicação oferece **feedback proativo em tempo real**, orientando o usuário sobre enquadramento, estabilização e geometria antes mesmo do clique.

---

## 🚀 Funcionalidades Principais

* **🎯 Enquadramento Fotográfico Inteligente:** Detecta sujeitos descentralizados e orienta o usuário (ex: *"Que tal dar um passo para a direita?"*).
* **🎥 Estabilização de Vídeo:** Emite alertas dinâmicos de estabilização durante gravações contínuas.
* **📄 Geometria de Documentos:** Auxilia na detecção de bordas e corte ideal para digitalizações limpas.
* **⚡ Exportação Sob Medida (Presets):** * *TikTok:* Proporção vertical 9:16 com taxa de compressão adaptada.
  * *Instagram:* Otimização cromática e nitidez para Feed, Reels e Stories.
  * *Documentos:* Correção de posicionamento e contraste otimizados para PDF.
* **📂 Flexibilidade de Entrada:** Suporte para captura via câmera em tempo real (streams de hardware), upload local (JPG, PNG, MP4, PDF) e acesso à biblioteca.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído focando em alta performance, arquitetura limpa e baixo consumo de memória, utilizando apenas tecnologias nativas no front-end:

* **HTML5 Semântico:** Estrutura acessível com tags semânticas e viewport *mobile-first*.
* **CSS3 Moderno:** Variáveis customizadas, Flexbox, Grid e animações sutis de interface.
* **Tailwind CSS:** Framework utilitário para design responsivo e fluidez visual.
* **JavaScript Vanilla:** Jornada 100% dinâmica orientada a eventos, manipulação de DOM e gerenciamento de estados.
